# React Native Task Manager

A mobile task management application built using React Native and Expo. This app helps users organize daily tasks, set priorities, manage due dates, and track their productivity.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed or pending
- Set task priorities (High, Medium, Low)
- Set due dates using a date picker
- Search tasks by title
- Filter tasks by All, Pending, Completed, and Overdue
- Sort tasks by Recent, Due Date, and Priority
- View task details
- Track task statistics and completion progress
- Light Mode and Dark Mode
- Save tasks locally using AsyncStorage

## Technologies Used

- React Native
- Expo
- JavaScript
- React Hooks (useState, useEffect)
- React Navigation
- AsyncStorage
- React Native DateTimePicker
- Expo Vector Icons

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/subitha990527/React-Native-Task-Manager.git
   ```

2. Navigate to the project folder:

   ```bash
   cd React-Native-Task-Manager
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the Expo development server:

   ```bash
   npx expo start
   ```

5. Scan the QR code using Expo Go on your Android device.

## Data Storage

Tasks are stored locally on the device using AsyncStorage, allowing task data to remain available after closing and reopening the app.
